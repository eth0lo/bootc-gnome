# bootc-gnome

Terms for distinguishing operating-system, application, and firmware updates
in this bootc-based desktop image.

## Language

**OS update**:
An update to the installed operating-system image, delivered through bootc.
_Avoid_: system package update

**Application update**:
An update to an application managed as a Flatpak.
_Avoid_: OS update

**Firmware update**:
An update to supported device firmware managed through fwupd.
_Avoid_: OS update
