# Stage operating-system updates before reboot

The image will periodically stage updates with `bootc upgrade` without `--apply`, so the update never initiates a reboot and is activated at the next normal reboot. Successful checks are daily; deferred metered/unknown-network checks and transient failures retry approximately every two hours. Automatic downloads are allowed only when NetworkManager reports an unmetered connection, and the updater uses low CPU and I/O priorities while preserving the installation's configured image reference. If a deployment fails its first boot health check, the intended recovery is to select the previous deployment on the next boot and suppress that failed image digest until the tracked channel changes; this recovery behavior is accepted policy but remains unimplemented pending validation of the installed GRUB/OSTree boot configuration.
